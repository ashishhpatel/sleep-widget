Upload index.html, connect.html, callback.html to the ROOT of your GitHub repository, replacing index.html and callback.html. Keep your existing privacy.html and terms.html.
Visit https://ashishhpatel.github.io/sleep-widget/connect.html to start OAuth.
Use the SAME browser tab for authorization and callback so the state check succeeds.
This flow returns an access token (valid approximately 30 days) but does NOT install it into Scriptable or auto-refresh it. Do not share the token or commit it to GitHub.
