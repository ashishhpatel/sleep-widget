Privacy Policy

My Sleep Widget is a personal, noncommercial project for displaying sleep data from Oura and Apple Health.

This public website hosts informational pages and an Oura OAuth callback. The callback processes an authorization response in the browser and does not intentionally send access tokens or sleep data to the website owner or a separate application server. GitHub Pages and the user's browser/network providers may process normal website request metadata.

When the iPhone widget is configured, sleep data and Oura credentials should be kept in private device storage, not in the public GitHub repository. Oura API requests are made to Oura and are subject to Oura's policies. Access may be revoked through Oura account settings.

This statement describes the intended implementation; update it if functionality or storage practices change.
